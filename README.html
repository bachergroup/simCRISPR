simCRISPR

simCRISPR is an R package for simulating pooled CRISPR screening data under various experimental designs. It models biological and technical variability, including sgRNA knockout effects, treatment and interaction effects, PCR amplification, and sequencing noise. The framework is designed to support method development and benchmarking in CRISPR analysis.

Installation

You can install simCRISPR from GitHub using:
